# DevFlow 操作安全契约

本契约定义项目管理与恢复功能在实现前必须遵守的边界。

## 不可变边界

- DevFlow 的项目删除、归档和恢复操作不得删除或修改 GitHub 仓库。
- 已结束 Run 的 DAG、事件、证据和验证结论只读；不得通过恢复操作原地重开。
- 恢复必须创建新的关联 Run，并保留来源 Run 标识。
- DevelopmentSession 的计划、检查点和工作包进度仅用于生成后续 Run，不授权篡改旧 Run 事实。

## 确认与审计

- 归档、永久删除、继续开发和重新规划均须先获得服务端确认。
- 未确认的删除仅能返回影响预览，不得写入项目、运行、缓存或凭据。
- 已确认的管理操作必须追加一条 `operation_audits` 记录；审计记录不包含令牌、密码或凭据。
- 永久删除未来仅删除 DevFlow 本地数据与受管缓存，绝不删除远端 GitHub 内容。

## 状态转换

状态转换以 `backend/app/models/lifecycle.py` 为唯一代码契约。后续归档、删除和恢复命令必须先验证转换合法性，且不得为已结束 Run 添加返回 `RUNNING` 的转换。
